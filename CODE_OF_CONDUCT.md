# Code of Conduct

We pledge to make participation in this project a harassment-free experience for everyone. Be respectful, assume good intent, give actionable technical feedback, and do not publish another person's private information.

Project maintainers may remove comments, commits, issues, or contributions that violate these expectations and may temporarily or permanently restrict participation. Report conduct concerns privately through the maintainer's GitHub profile.

This compact policy will be replaced with the current Contributor Covenant text before the first public release if community participation begins.
